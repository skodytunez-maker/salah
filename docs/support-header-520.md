# Обращения520

База: публичная518, commit8bac874389ddd29781852d7534ff2aada01b89e5. Новое живое небо519 не включено.

- Шапка учитывает системный fade iPhone ниже safe area: ещё min(40px,safeTop), как существующая панель мусхафа. При нулевом inset дополнительного отступа нет. Изменение только в Support.
- Аватар — кнопка только для владельца. Использует существующую приватную карточку, прежние owner-access запросы и session/MFA проверки. Новые привилегии администраторам не добавляются.
- Карточка располагается поверх смонтированной переписки. Назад и pointer-swipe закрывают только карточку; чат, место и черновик сохраняются. Идентификатор пользователя не помещается в URL или постоянное хранилище.
- Повторная успешная проверка того же владельца сохраняет mount. При настоящей повторной авторизации checkpoint остаётся только в памяти и привязан к аккаунту и режиму owner/user. Другой аккаунт не получает старые чат и черновик. Выход из раздела и новый запуск очищают checkpoint.

Проверки исполняют реальные DOM/CSS/gesture/history функции; HappyDOM не заменяет проверку Safari на физическом iPhone. Проверить отступ имени и возврат после переключения приложений на телефоне. Backend, обои, небо, счётчики, проигрывание, религиозные тексты, новость515 и внешний push не изменены. Награды и названия сур идут следующим пакетом согласно уточнённому приоритету владельца.
