# Peshawa portrait background

The original Way2Quran portrait remains at
dist/assets/reciters/peshawaalkurdi.jpg. The user requested the standard SALAH
portrait background. The derived file is peshawaalkurdi-salah-420.jpg.

Created with the built-in image_gen edit tool, using the original as the edit
target and the existing Yasser ad-Dossari portrait only as a charcoal background
reference. The result was visually checked for identity and framing, then
resized to the existing 700×700 catalogue size and encoded as JPEG for delivery.
This is a derived image, not an unmodified source photograph. No additional
redistribution license or ownership is claimed.

Prompt: Replace only the outdoor background with the existing SALAH portrait
style, near-uniform charcoal gray (#242424), with a subtle studio gradient.
Preserve the original face, expression, hair, beard, head position, blue jacket,
white shirt and framing. Add no rim light, halo, text, logos, symbols, objects or
watermark. The reference man must not appear or influence the target identity.
