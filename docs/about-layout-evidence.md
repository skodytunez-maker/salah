# About layout

The user-selected About mockup supplied on2026-10-19 is the visual target. The screen reuses the approved transparent SK asset, existing Prata/Manrope fonts and actual Instagram links. The selected layout uses a back link, serif title, centered SALAH heading, one founder row and plain social rows. Mobile navigation precedes the author footer on this route; other routes keep their existing navigation.

The additional chevron is from Bootstrap Icons (https://github.com/twbs/icons/blob/8d88686c03c3768a2d82ba4f20c3c4e1b100fa29/icons/chevron-left.svg), covered by the existing dist/assets/bootstrap-icons-LICENSE.txt. This stock icon is not a redrawn brand asset.
