# Russian tafsir reader

As-Saadi and Ibn Kathir are separate commentary editions, never replacements for Arabic Quran or Kuliev translation. Access via the verse action menu. Author selection persists; opened ayahs are cached for offline reading and removed by Clear cache.

Provenance: QUL resources 170 and 307; immutable mirror spa5k/tafsir_api at eb82bb6294efe30ad5c135c03b1864afaa70e855. The mirror supplies per-ayah Russian text. Version and source links remain visible. Files are requested from jsDelivr with a raw GitHub fallback and no credentials/referrer; user audio or account data is never sent. The texts are not rewritten or machine-translated. Grouped passages may repeat for adjacent ayahs according to the source mapping.

Verification: source JSON must match the requested surah and ayah and contain non-empty bounded text. Render via textContent, not provider HTML. A new author/ayah or closed dialog aborts the previous request; stale responses cannot replace the current reading.

Rights evidence remains resource-specific and needs review; an open mirror is not a blanket copyright clearance. QuranEnc Russian Saadi browser was located, but its API did not list/return this edition during verification, so it is not used as a fake fallback.
