## Проект реферата
SALAH — приложение для отображения времени намазов по выбранному городу, чтения и прослушивания Корана, повседневных дуа и азкаров, определения направления Киблы и изучения порядка совершения Умры. Программа предоставляет настройки расписания, чтения и оформления, сохраняет пользовательские данные и незавершённые этапы чтения. Реализованы web/PWA-интерфейс, оболочка Capacitor для мобильных платформ, виджеты расписания, аккаунт и обращения в поддержку.
Основные языки: JavaScript, HTML, CSS; нативные части — Java и Swift, конфигурационные скрипты используют также Ruby. Сторонние библиотеки и материалы перечислены в реестре прав отдельно от собственных частей проекта.
Точный объём, перечень ОС и описание материалов для депонирования формируются по версии, выбранной для заявки. Этот текст не заявляет личное написание всего кода человеком.
