# Candidate515 — glass, messenger actions and retained Home weather

Status: public515 explicitly authorized by the owner after delivery of the concrete private candidate. Release common features in the normal installed app; keep the new sky closed to ordinary users. Apply the reviewed backend migration/function before the frontend. No external update push or real-message deletion test is authorized or performed. Physical-phone verification is not claimed.

## Requested behavior

Optional glass mode lives only in Appearance. The Home timetable and collapsed player have independent transparency sliders and a local preview. Existing appearance remains the default. The controls preserve the current wallpaper, text, photographs and playback controls. The native/fullscreen player is unchanged. Save failures roll back only the three glass preferences; restore/import updates stable Settings references without discarding other drafts.

Personal/team messenger uses SALAH navy/gold bubbles, an explicit accessible message-action button and a bounded touch hold. Actions are Reply, Copy, Delete for me and, for the author, Delete for everyone. Reply cancellation keeps the typed draft. Failed requests do not claim deletion or discard composer text/files. Whole-chat deletion also offers Self and Everyone with explicit confirmation. Self hides only that account’s previous history and personal-chat inbox entry; the fixed team-room address remains available. A future message makes the conversation visible again. Direct participants may clear their shared previous history; only the verified owner may clear the whole team room. Room membership and future messaging remain available. No calls, reactions, forwarding or save placeholders are introduced. The support-ticket view retains its approved markup. The owner-provided Telegram group screenshot guides the group-only sender gutter, circular avatar fallback and distinct readable sender colours. Existing authorized avatar hydration is reused only where already permitted; no online counts or role badges are fabricated. Direct bubbles and support remain separate.

Private SQL visibility is scoped to the authenticated participant. Selected-message Everyone deletion redacts only the author's own message. Whole-room clear applies the separately authorized participant/owner rule and invalidates all affected history/attachment views. Read responses reconstruct reply quotes from currently visible targets and filter hidden/redacted attachments. Room revisions and actor-specific hide versions invalidate older pages. Old account/view responses must not overwrite a new composer, including authorization failures. Before transport, bind delayed destructive requests to the initiating actor; an account switch aborts the old intent before fetch. Already issued signed URLs expire after their existing five-minute lifetime; downloaded copies cannot be recalled. A pre515 client can retain an older page already cached in RAM until remount/update because it does not understand the new revision marker. Fresh server reads are filtered for all clients; instant erasure of old-device copies is not claimed. No messages from real users are used for mutation tests.

The reported Home return issue was reproducible on the actual weather controller: leaving Home immediately set its retained cloud/fog snapshot to zero, so each return replayed the six-second clear-to-cloudy transition. Home departure now pauses drawing while retaining the snapshot and transition clock. Fresh weather still transitions normally; disabled/stale weather, hidden pages and reduced motion keep their existing policies. The new sky remains unavailable to ordinary users and requires explicit owner opt-in; no photos, foreground mattes or astronomical paths are replaced.
