# Azkar hub and personal short-dhikr counter

The five main collection cards use the existing Knowledge surface, border, typography and gold icon accents. The personal counter is a full collection card. On normal portrait phone sizes the hub shares the available safe viewport height; short viewports and enlarged text can still scroll instead of clipping actions.

The eight built-in short formulas have Arabic text and a short meaning. Users can choose a personal repetition target and add up to twenty named texts. No fixed target or new religious reward is assigned to the added formulas. The original round is retained as Subhanallah because that was the formula previously displayed by the free-counter page.

Each formula keeps a device-local current round and target inside the existing account-isolated salah:dhikr-free record. The original free-dhikr lifetime remains the only cloud counter identity, so switching formulas, removing a custom text or resetting one round cannot create lifetime credit. Existing locking, atomic rollback and account-switch protection remain in use. Counts are added only by deliberate taps. New fields are validated and included in the existing backup/restore workflow. Formula names, custom texts and individual local rounds are not newly uploaded to the counter service.

The update is based on public416 and excludes the unpublished private classroom417 implementation. Public learning gates and other account permissions are unchanged. New illustrated announcement418 describes only this feature.
