# SALAH: проверка материалов без внешних обращений

Статус: **no-outreach**, решение владельца от 7 октября 2026. Запросы фотографам, издателям, аудиопровайдерам и другим правообладателям не отправлять. Письма до этого решения также не отправлялись.

Файл сохраняет прежнее имя для существующих ссылок. Предыдущие шаблоны писем доступны в истории Git; они выведены из текущего плана и не являются разрешением или незавершённой задачей на отправку.

Порядок работы:

1. Сохранить выбранные обои и доступные записи их генерации для SALAH.
2. Записать лицензии конкретных фотоориентиров отдельно от происхождения готовых иллюстраций.
3. Проверить подходящие опубликованные условия перед назначением дополнительных действий. Не считать каждый фотоориентир переработкой и не считать генерацию автоматическим разрешением на сторонний материал.
4. Для текстов и аудио установить точные источники, способ использования и действующий объём условий: бесплатный режим, офлайн, будущие платные функции, промофрагменты.
5. Если разрешённый объём пока не установлен, сохранить открытый вопрос. Самостоятельный текст, запись или независимый источник можно подготовить отдельной проверенной правкой; выбранные пользователем материалы не заменять автоматически.

Решение не обращаться является рабочим ограничением, а не документом правообладателя. [Основной отчёт](rights-audit.md) и [лицензии четырёх фотоориентиров](wallpaper-reference-licenses.json) содержат результаты текущей проверки. Личные контакты владельца здесь не публикуются.

При конкретном обращении о материале: сохранить текст и точный объект обращения, установить затронутые файлы/ссылки, проверить действующие условия и подготовить замену отдельной правкой с проверками. Для обоев сохранить совпадение дня, ночи, маски неба и погодных эффектов; для аудио — функцию воспроизведения; для текстов — смысл и проверку чтения. Ответы адресату и обещания от имени владельца без отдельного указания не отправлять.
